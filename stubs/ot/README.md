# ot stubs

## Overview

Type stubs for the parts of POT (Python Optimal Transport) this package calls, because POT ships no types.

## Components

| Component | Description |
|-----------|-------------|
| [\_\_init\_\_.pyi](./__init__.pyi) | `emd`, `sinkhorn`, and `dist`. |
| [unbalanced/](./unbalanced/README.md) | Unbalanced Sinkhorn. |
| [partial/](./partial/README.md) | Exact partial transport. |
| [gromov/](./gromov/README.md) | Exact and entropic Gromov-Wasserstein. |
